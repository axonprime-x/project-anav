# Project ANAV // Multi-Network Integration & Exposition Roadmap

## Executive Summary
This document outlines the strategic integration framework for expanding Project ANAV's autonomous M2M ingress and compute mesh across three premier decentralized networks: **io.net**, **Vast.ai / Salad Cloud**, and **Farcaster & Base Agent Registries**, operating alongside our active **Akash** deployment.

---

## 1. Integration Blueprint

### Phase 1: io.net (DePIN GPU Aggregation)
- **Objective:** Pool local hardware resources and idle compute cycles into distributed AI inference clusters.
- **Action Plan:**
  - Expose the local MCP and telemetry endpoints (`/api/v1/mcp`) to io.net's worker daemon.
  - Automate bounty collection and high-frequency machine learning task allocation.

### Phase 2: Vast.ai & Salad Cloud (Spot-Market Bridging)
- **Objective:** Dynamically list containerized workers on decentralized spot rental marketplaces.
- **Action Plan:**
  - Deploy lightweight spot-market worker containers.
  - Implement automated rental hooks to monetize idle local compute cycles when spot demand spikes.

### Phase 3: Farcaster & Base (On-Chain Agent Discovery)
- **Objective:** Broadcast ERC-8004 Agent Card manifests and x402 payment requirements on-chain and via social channels.
- **Action Plan:**
  - Maintain active publishing of `agent-card.json` and discovery sitemaps.
  - Interface directly with on-chain crawlers and indexers for instant transaction settlement.
