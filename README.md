# Project ANAV // Decentralized M2M & Compute Mesh

Project ANAV is a mesh-native, collectivist decentralized architecture engineered for resilient machine-to-machine (M2M) micropayments, automated liquidity bridges, sybil resistance, and distributed compute scaling under persistent systemd supervision.

## Key Capabilities
* **Global x402 Ingress Gateway:** Enforces HTTP 402 "Payment Required" compliance, verifying cryptographic Base and Solana USDC micropayment proofs.
* **ERC-8004 Agent Card Manifest:** Fully discoverable agent identity registry at `/.well-known/agent-card.json`.
* **Hardware Compute Bridge:** Direct AMD Ryzen/AM5 CPU/GPU spare capacity pooling and bounty verification.
* **Live SQLite Ledger:** Immutable runtime cryptographic proof recording.

## Public Discovery Endpoints
* **Agent Card:** `/.well-known/agent-card.json`
* **Crawler Directives:** `/robots.txt`
* **Sitemap:** `/sitemap.xml`
